# Aurora — Visual Music Player

纯前端、零依赖的可视化音乐播放器。上传本地 MP3，随声起舞的霓虹可视化。

## 功能
- 拖拽 / 点击上传 MP3（支持多首）
- Web Audio API 实时频谱分析
- 四种可视化模式：融合 / 环形 / 频谱 / 波形
- 节拍粒子、贝斯呼吸光晕、中心黑胶旋转
- 播放列表、进度/音量控制、键盘快捷键
- 6 套主题配色（霓虹/日落/深海/森林/糖果/极简），一键切换，本地记忆

## 使用
浏览器直接打开 `music-player.html`，拖入 MP3 即可。

## 快捷键
- Space 播放/暂停
- 左右箭头 快退/快进 5 秒
- 上下箭头 音量
- N / P 下一首 / 上一首
